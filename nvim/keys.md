# 操作一覧

> [!TIP]
> 閉じるときは右上の × か `q`。原文で見るときは上の「原文」をクリック。

## 窓と pane

リモートでは tmux に、Windows では WezTerm に効く。

| キー | 動作 |
|---|---|
| `Shift+Alt+-` | 上下に分割 |
| `Shift+Alt++` | 左右に分割 |
| `Shift+Alt+W` | pane を閉じる |
| タブの `×` | タブを閉じる(毎回確認。窓の `×` はまとめて 1 回だけ確認) |
| `Shift+Alt+Z` | pane の最大化 / 戻す |
| `Shift+Alt+矢印` | pane の大きさ |
| `Shift+Alt+E` | ツリーを出す / ツリーへ移る / 閉じる |
| `Shift+Alt+S` | 最下段のステータス行を出す / 隠す(リモート) |
| `Shift+Alt+O` | フォルダを開く(リモートとこの PC。最後に指示を出した日時つき) |
| `Shift+Alt+P` | この PC のフォルダを開く |
| `Shift+Alt+N` | 新しいタブ |
| `Shift+Alt+R` | 前の作業を再開(3 日以内の Claude Code の会話を選んで、場所ごとのタブで開く)。Tab でフォルダを開く一覧に切り替え |
| タブバーの `＋` | 新しいタブ / フォルダを開く / 前の作業を再開 / タブを選ぶ |
| `Shift+Alt+T` | テーマの切り替え |
| `Shift+Alt+K` | コマンドパレット |
| `Shift+Alt+L` | タブを選ぶ(一覧から名前で探して移る。タブが多いと題名が縮むため) |

## ツリー

| 操作 | 動作 |
|---|---|
| ダブルクリック / `Enter` | フォルダは開閉、ファイルは上のエディタで開く |
| 右クリック / `M` | メニュー |
| `Ctrl+P` | ファイル名で探す(開いているフォルダの中) |
| `Ctrl+F` | 文字列で探す |
| 最下段の Git の表示をクリック | Git(Lazygit)を開く |
| ファイルをドロップ | 配置先を選ぶ(下の「ドロップ」) |
| 確認・入力 | ツリーの下に出る。`Enter` 決定 / `Esc` やめる |
| `V` で範囲を選んで `d` | まとめて削除(確認あり) |
| `󰁅 配置先` の印 | ドロップしたときの最初の配置先(カーソルの行のフォルダ) |
| `O` | アプリで開く |
| `E` | エクスプローラーで表示 |
| `Y` | パスをコピー |
| `g` | Git(Lazygit) |
| `a` / `A` | 新しいファイル / 新しいフォルダ |
| `r` / `d` | 名前の変更 / 削除 |
| `y` / `x` / `p` | コピー / 切り取り / 貼り付け(ツリーの中で) |
| `c` / `m` | 複製 / 移動(行き先を入力) |
| `H` | 隠しファイルの表示切り替え |
| `/` | 絞り込み |
| `R` | 更新 |
| `?` | この一覧 |
| `q` | ツリーを閉じる |

### ドロップ

- フォルダをクリックすると配置先になり、開く / 閉じる
- キーでは `j` / `k` で移り、`Space` / `l` / `→` で開閉、`h` / `←` で閉じる
- `Enter` で配置、`Esc` でやめる

### 検索の画面

- 上のエディタの中に出る。右上の `×`・画面の外のクリック・`Esc` で閉じる

## エディタ(上段)

| 操作 | 動作 |
|---|---|
| タブをクリック | 切り替え |
| タブの `×` / 中クリック | 閉じる(未保存は `●`。閉じるときに確認) |
| `H` / `L` | 前 / 次のタブ |
| `Space x` | タブを閉じる |
| `Space v` | Markdown のプレビュー / 原文 |
| `Ctrl+P` / `Ctrl+F` | ファイル名で探す / 文字列で探す |
| `:w` | 保存 |

## タブの印(Claude Code)

| 印 | 意味 |
|---|---|
| 時計 | 作業中 |
| ベル(タブがオレンジ) | 確認を求めている(Windows の通知も出る) |
| チェック | 応答を終えた(Windows の通知も出る。その pane を見ると消える) |

## コピー・貼り付け

| 操作 | 動作 |
|---|---|
| ドラッグ | 選ぶと、離したときにコピーされる(Claude Code の上では Claude Code が選ぶ) |
| `Shift+ドラッグ` | Claude Code の上でも WezTerm で選ぶ(離したときにコピー) |
| `Ctrl+C` | 選択中ならコピー(エディタでも)、無ければ中断 |
| `Ctrl+V` | 貼り付け(どこでも) |
| 右クリック | リモートのシェルでは、範囲選択中ならコピー |
| `Alt+V` | Claude Code に画像を貼る |
| `Shift+Enter` / `Alt+Enter` | Claude Code の改行 |

## Lazygit(よく使うもの)

| キー | 動作 |
|---|---|
| `Space` | ステージ / 解除 |
| `c` | コミット |
| `P` / `p` | push / pull |
| `Enter` | 中を見る |
| `q` | 閉じる |
| `?` | Lazygit の操作一覧 |
